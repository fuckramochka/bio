# 🌐 Bio & Portfolio (Клон сайта rooni.dev)

Точная копия дизайна, верстки, анимаций и интерактивных компонентов сайта `rooni.dev`.

---

## 📁 Структура проекта

```text
bio/
├── index.html           # Главная страница (разметка, контент и скрипты)
├── style.css            # Стили темы, 3D телефона, дашборда и каруселей
├── icon.png             # Фавикон страницы
├── assets/
│   ├── common.css       # Базовые стили лейаута, скролла, шрифтов и анимаций
│   └── common.js        # Движок полноэкранного скролла, свайпов и частиц
├── 1plus_anim/
│   ├── before.webp      # Текстура экрана 3D-телефона
│   └── back.webp        # Текстура задней крышки 3D-телефона
└── README.md            # Данная инструкция по настройке
```

## 🚀 Как запустить локально

Вы можете открыть `index.html` прямо в любом современном браузере (Chrome, Edge, Firefox, Safari) или запустить локальный веб-сервер:

### Вариант 1: Через Python
В терминале внутри папки `bio`:
```bash
python -m http.server 8080
```
Затем откройте в браузере: `http://localhost:8080`

### Вариант 2: Через VS Code Live Server / Antigravity
Просто кликните правой кнопкой мыши по `index.html` и выберите **"Open with Live Server"**.

## 🎨 Как настроить сайт под себя (Кастомизация)

Все основные данные находятся в файле `index.html`. Ниже приведены инструкции по каждому блоку:

### 1. Основной цвет и акценты (`index.html` и `style.css`)
В блоке `<style>` в шапке `index.html` или в `style.css`:
```css
:root {
    --primary: #ffffff; /* Замените на любой HEX цвет, например #a855f7 или #38bdf8 */
    --acc: var(--primary);
}
```

### 2. Главный экран (Intro / Hero)
Найдите секцию `<section class="sec" id="hero">`:
- **Аватарка**: замените URL видео в `<video src="...">` или замените тег `<video>` на обычное фото `<img src="avatar.jpg" class="media" alt="Avatar">`.
- **Заголовок**: измените `<h1>Rooni</h1>` на свой никнейм/имя.
- **Био**: отредактируйте текст в `<p class="bio">...</p>`.

### 3. Ссылки и соцсети (Connect & Links)
Найдите секцию `<section class="sec" id="links">`:
- В слайде `Connect with me` замените ссылки `href="https://t.me/..."`, `mailto:...`, `discord.com/...`.
- В слайде `My Channels` добавьте или измените ссылки на свои каналы, блоги и репозитории.

### 4. О себе и Стек технологий (About Me)
Найдите секцию `<section class="sec" id="about">`:
- Измените никнейм, имя, возраст.
- **Часовой пояс**: в скрипте внизу `index.html` найдите `timeZone: 'Asia/Krasnoyarsk'` и укажите свой (например, `'Europe/Moscow'`, `'UTC'`, `'Asia/Almaty'` и т.д.).
- Измените карточки в блоках `Стек технологий` и `Мой ПК`.

### 5. Проекты и Портфолио (Portfolio & Works)
Найдите секцию `<section class="sec" id="projects">`:
- Каждая карточка — это ссылка `<a href="..." class="project-card">`.
- Отредактируйте название проекта (`pj-title`), описание (`pj-desc`) и иконку Material Symbols (`forum`, `dns`, `shield`, `code`, `globe` и др.).

### 6. Секция 3D смартфона (My Device)
Найдите секцию `<section class="sec" id="phone">`:
- Измените название устройства (`OnePlus 13` -> например, `iPhone 16 Pro` или `Samsung Galaxy S24 Ultra`).
- Измените чипы характеристик и карточки спецификаций (процессор, дисплей, батарея, камера).
- Чтобы сменить текстуры на 3D модели, положите новые изображения в папку `1plus_anim/` с именами `before.webp` (лицевая) и `back.webp` (задняя).

### 7. Интеграция со статистикой (Яндекс Музыка и Telegram)
Внизу `index.html`:
- По умолчанию включен умный Fallback: если бэкенд не подключен, выводятся красивые демо-данные без ошибок.
- Вы можете указать реальные API-эндпоинты в константах:
  ```js
  const MUSIC_API = '/music_watcher/?api=1';
  const TG_API = '/tg_time/index.php?api=1';
  const MUSIC_STATS_API = '/music_watcher/?stats=1';
  ```
